# 📘 Blacktokki Notebook 사용자 가이드

**Blacktokki Notebook**은 마크다운 기반의 **지식 관리 및 시간 관리 도구**입니다. 사용자는 다양한 주제의 노트를 자유롭게 작성하고 구조화하며, 일정과 연결하여 추적할 수 있습니다. 모바일과 웹 환경에서 모두 사용할 수 있으며, **자기 주도 학습**, **업무 관리**, **지식 아카이빙**, **회고 기록** 등에 유용하게 활용할 수 있습니다.

## 주요 특징

- ✅ 마크다운 에디터를 통해 자유롭게 노트를 작성할 수 있습니다
- 📁 폴더와 하위 노트 구조로 내용을 계층적으로 정리할 수 있습니다
- 🧭 문단 제목을 기반으로 자동 생성되는 트리 뷰로 빠르게 탐색할 수 있습니다
- 🔍 제목과 문단 이름, 링크, 키워드까지 포함한 고급 검색 기능을 제공합니다
- 🔁 특정 문단을 다른 노트로 이동할 수 있습니다
- 📆 일정 정보를 자동으로 감지하여 타이머 형태로 시각화할 수 있습니다
- 🧠 자동완성 기능으로 링크와 자식 노트를 빠르게 작성할 수 있습니다
- 🧳 Markdown/JSON ZIP 아카이브 형식으로 노트와 보드를 내보내거나 다시 가져올 수 있습니다

## 시작하기 (Getting Started)

### 🔍 노트 검색 및 생성

- 상단 검색창에서 키워드 입력 시 기존 노트 탐색 및 새 노트 생성 가능
- 새로운 제목 입력 후 `Enter` 키를 누르면 자동으로 해당 노트 생성 및 진입

### ✏️ 노트 편집

- 마크다운 기반 에디터 제공
- 자동완성 트리거:
  - `[` → 내부 노트 링크. `[키워드` 입력 시 다른 노트 제목뿐만 아니라 **현재 노트의 문단 제목** 또는 **새로운 하위 노트(예: `현재노트/키워드`)** 생성을 제안합니다.
  - `http` → 외부 링크 미리보기

## 화면별 기본 사용법

### 🏠 홈

- 첫 진입 시 가장 먼저 보이는 메인 화면입니다
- 최근 열람한 노트 목록, 편집 제안, 타임라인 기능에 빠르게 접근할 수 있습니다
- 모바일 환경에서는 하단 탭으로 주요 메뉴에 접근하며, 웹에서는 좌측 메뉴(Drawer)를 통해 모든 기능에 빠르게 이동할 수 있습니다

### 📄 노트 페이지

- 노트의 제목과 본문, 그리고 구조화된 문단 목록이 함께 제공됩니다
- 사이드에 표시되는 문단 목록은 노트 내 제목(H1~H6)을 기반으로 자동 생성되며, 클릭 시 해당 위치로 이동합니다
- 상단 버튼을 통해 노트를 편집하거나, 문단 이동 또는 편집 이력을 확인할 수 있습니다
- `[문서](../폴더/문서%20제목.md)` 같은 상대 경로 링크로 다른 폴더의 노트를 열 수 있습니다. `#문단` 링크는 현재 노트의 해당 문단을 엽니다.

### ✏️ 노트 편집

- 위지윅/마크다운 형식으로 작성 가능한 에디터 화면입니다
- 노트의 본문을 자유롭게 작성하거나 수정할 수 있으며, 자동 저장 기능과 수동 저장 기능이 모두 제공됩니다
- 내부 노트 링크, 외부 링크 자동완성 기능을 활용할 수 있습니다
- `[` 자동완성으로 연결할 노트나 문단을 선택하거나, 내부 링크를 붙여넣을 수 있습니다.

### 🗂 최근 노트

- 사용자가 가장 최근에 열람하거나 작성한 노트들을 카드 및 그리드 형태로 나열하여 보여줍니다
- 상단 우측의 뷰 모드 전환 아이콘을 클릭하여 하위 노트 목록, 칸반 보드, 스크럼 보드 등 다양한 보기 모드로 직관적으로 전환할 수 있습니다 (단, 간단 모드에서는 하위 노트 목록 모드로 고정됩니다)
- 클릭 시 해당 노트로 바로 이동하며, 원하지 않는 노트는 리스트에서 제거할 수 있습니다

## 사용 모드 (Usage Mode)

사용자의 작업 스타일과 목적에 맞춰 앱의 복잡도와 제공되는 기능을 3단계로 조절할 수 있습니다.

- **빠른 전환:** 화면 상단의 앱·노트북 이름을 눌러 노트북을 바꾸거나 추가합니다. 노트 모드로 돌아가거나 노트북 설정을 열 수도 있습니다.
- **설정 메뉴:** `설정 > 노트 설정 > 모드 설정`에서도 모드를 변경할 수 있습니다. 등록된 노트북이 없으면 새 노트북 만들기 화면이 열립니다.
- 로컬 모드에서 새로고침하면 마지막으로 선택한 사용 모드와 노트북이 복원됩니다. 삭제된 노트북이나 잠긴 프라이빗 노트북은 노트 모드로 돌아갑니다.

### 🌱 간단 모드 (Simple Mode)

최소한의 필수 기능만 제공하는 가장 가벼운 메모 환경입니다. 빠른 메모 작성과 열람에 집중하고 싶을 때 유용하며, 불필요한 UI(확장 기능, 변경내역 등)가 숨겨집니다.

### 📝 노트 모드 (Note Mode)

보드 기능이나 프라이빗 기능 없이 순수하게 문서 작성 및 지식 관리에 집중할 수 있는 기능들을 제공합니다. 본격적인 정보 구조화, 확장 기능 활용이 필요한 사용자에게 적합합니다.

- **🗃 아카이브**
  - 저장된 노트의 이전 버전(스냅샷)을 확인할 수 있는 화면입니다
  - 노트 제목별로 과거 저장 시점의 내용을 시간순으로 비교할 수 있습니다
  - 버전 관리와 과거 내용 복원이 필요할 때 유용하게 사용됩니다

### 📓 노트북 모드 (Notebook Mode)

앱이 제공하는 기능을 목적에 맞는 '노트북' 단위로 나누어 사용할 수 있는 환경입니다. 각 노트북 생성 시 일반 워크스페이스, 프라이빗 워크스페이스, 프라이빗 노트 등의 하위 모드를 지정하여 독립된 공간으로 격리하여 사용할 수 있습니다.

- **헤더 드롭다운을 통한 노트북 관리:**

  - 상단 헤더의 노트북 이름을 클릭하면 현재 등록된 노트북 목록이 표시되며, 원하는 노트북을 선택해 즉시 작업 공간을 전환할 수 있습니다.
  - 노트북 항목 우측의 메뉴(⋮) 버튼을 눌러 노트북의 제목, 설명, 하위 모드 등 설정을 수정하거나 삭제할 수 있습니다. 현재 접속 중인 노트북 모드를 삭제하면 자동으로 기본 노트 모드로 복귀합니다.
  - `+ 새 노트북 모드 추가` 버튼으로 새로운 노트북을 손쉽게 생성할 수 있고, `〈 노트 모드로 변경` 버튼으로 기본 노트 모드로 빠르게 복귀할 수 있습니다.

- **🗂 일반 워크스페이스 (Workspace)**

  - 노트의 문단들을 칸반/스크럼 보드 형태로 시각화하고 관리할 수 있는 기능이 포함된 노트북입니다.
  - 메모와 문서 관리를 넘어 프로젝트 및 일정 관리까지 병행할 때 추천합니다.

- **🔐 프라이빗 노트 & 워크스페이스 (Private)**
  - 공개적인 장소에서 노트를 열람하거나 화면 공유 시, 민감한 정보를 숨길 수 있는 노트북 타입입니다.
  - **프라이빗 모드 통합 관리:** 노트북 모드 선택 후 나타나는 프라이빗 모드(On/Off) 토글을 통해 모든 프라이빗 노트북의 잠금을 한 번에 관리할 수 있습니다.
  - **보안 강화 (OTP 인증):** '프라이빗 모드 진입 시 OTP 요구' 옵션을 활성화하면, 모드에 진입하거나 해당 보안 설정을 해제할 때 OTP 인증 모달을 통한 추가 검증을 수행합니다. (온라인 계정 및 OTP 활성 상태에서 지원)
  - **자동 해제 타이머:** '10분 미사용 시 자동 해제' 옵션을 켜두면, 마지막 활동 이후 10분간 조작이 없을 경우 프라이빗 모드가 자동으로 비활성화됩니다.
  - 모드가 꺼진(Off) 상태에서 URL 등을 통해 숨겨진 노트에 직접 접근할 경우, 경고 문구가 표시되며 내용을 볼 수 없습니다.

#### 🗂 보드

> 워크스페이스 타입 공통 기능

- 노트의 문단들을 칸반/스크럼 보드 형태로 시각화하고 관리할 수 있는 기능입니다.
- 최근 노트 화면 오른쪽 위의 아이콘으로 하위 노트 목록·칸반·스크럼·보드 설정을 전환합니다. 노트 제목 옆의 보드 아이콘으로 상위 보드에 돌아갈 수 있습니다.
- 홈의 보드/스크럼 뷰에서는 좌우 스크롤로 보드를 이동하고, 하단 탭을 눌러 다른 화면으로 이동합니다.
- 컬럼은 노트 이름순으로 정렬됩니다. 이름 앞에 번호를 붙여 순서를 정할 수 있습니다.
- 각 보드의 '컬럼(Column)'은 사용자가 지정한 **개별 노트**로 구성됩니다. (예: 'To Do' 노트, 'In Progress' 노트)
- 각 컬럼의 '카드(Card)'는 해당 노트 내의 **특정 레벨 제목(예: H2, H3)을 가진 문단**들로 자동 구성됩니다. (보드 설정에서 헤더 레벨 지정 가능)
- **스크럼 보드**의 행은 카드보다 한 단계 위의 제목으로 구분됩니다. 예를 들어 H3 문단을 카드로 사용하면 H2 제목이 행 이름이 됩니다.

- 카드를 드래그 앤 드롭하여 다른 컬럼으로 이동시킬 수 있습니다.
- 카드를 다른 컬럼으로 이동시키면, 해당 문단의 내용이 실제로 다른 노트로 이동됩니다. (예: 'To Do' 노트의 H3 문단을 'In Progress' 노트로 이동)
- 카드를 **한 번 클릭(탭)**하면 해당 문단을 읽을 수 있는 노트 화면으로 이동하며, **더블 클릭(더블 탭)**하면 즉시 내용을 수정할 수 있는 편집 화면으로 진입합니다.
- 내용이 없는 노트에서는 편집하기나 보드 생성 버튼으로 시작할 수 있습니다(간단 모드 제외).

## 고급 기능

### 📝 듀얼 에디터 지원

- 노트 편집 화면은 `M↓` 버튼으로 WYSIWYG 방식과 마크다운 방식 두 가지 모두를 자유롭게 변환할 수 있습니다.
- 두 편집 방식은 실시간으로 동기화되어 한쪽을 수정하면 다른 쪽에서도 바로 반영됩니다
- 사용자는 마크다운에 익숙하든, 시각적인 편집을 선호하든 모두 편리하게 작성할 수 있습니다

### 🏷️ YAML Frontmatter 보존 및 메타데이터 지원

- 문서 맨 위의 `--- ... ---`로 둘러싸인 메타데이터는 노트를 저장하거나 내보낼 때 유지됩니다.
- 시각적 편집 모드에서는 메타데이터가 숨겨집니다. 확인하거나 수정하려면 마크다운 모드로 전환하세요.

### 📑 문단 구조 자동 인식

- 노트에 작성된 제목은 자동으로 문단 구조로 변환되어 트리 형태로 표시됩니다
- 사용자는 이 트리를 통해 특정 문단으로 바로 이동하거나 전체 구조를 시각적으로 파악할 수 있습니다

### ⌞⌝ 문단 내용 전체 보기 기능

- 특정 문단으로 이동했을 때, 상단의 '펼치기' / '접기' 아이콘을 통해 해당 문단의 내용만 볼지, 하위 문단들의 내용까지 포함해서 볼지 토글할 수 있습니다.
- 하위 문단을 포함해서 보는 경우(펼치기), 해당 문단의 제목부터 모든 하위 문단의 내용이 하나의 노트처럼 표시됩니다.

### 🔗 링크 인식 및 연결

- 노트 내 삽입된 링크는 자동으로 인식되어 다른 노트 또는 외부 웹 페이지로 연결됩니다
- 다른 노트로 연결되는 링크는 검색이나 자동완성 결과에서 추천 항목으로 표시됩니다

### ⏱ 노트별 일정 자동 감지

- 타임라인에서 지원하는 날짜 형식으로 각 노트에서 작성된 일정을 자동으로 표시합니다
- 각 노트별 현재 일정은 타이머 바 형태로 시각적으로 표현되어 현재 상태를 쉽게 파악할 수 있습니다

### 🔍 검색 기록과 자동완성

- 검색한 키워드는 자동으로 저장되어 다음 검색 시 추천 항목으로 활용됩니다
- 최근 사용한 키워드를 빠르게 불러와 반복 입력을 줄일 수 있습니다

### 🔄 노트 및 문단 이동 (재배치)

- 전체 노트 또는 특정 문단을 다른 제목이나 위치로 이동하여 지식 구조를 재정비할 수 있습니다.
- **하위 노트 포함 이동**: 상위 노트의 이름이나 위치를 변경할 때, 해당 노트에 속한 모든 하위 노트를 한 번에 이동시킬 수 있습니다.
- **역링크 업데이트**: 다른 노트에서 이동한 노트나 문단을 가리키는 링크도 함께 갱신할 수 있습니다.
- **변경사항 미리보기**: 이동 전 구조 변경 내용과 텍스트의 변경점(Diff)을 미리보기로 확인하여 안전하게 편집할 수 있으며, 이동하려는 대상 노트가 이미 존재할 경우 경고를 확인하고 덮어쓸 수 있습니다.

### 💾 저장 방식과 계정 연결

- 로컬 계정과 온라인 계정 중에서 저장 방식을 선택할 수 있습니다. 온라인 계정의 노트는 동기화해 사용할 수 있습니다.
- 로컬 계정의 노트·간단 모드는 별도 폴더 설정 없이 브라우저에 저장됩니다.
- 로컬 계정의 노트북 모드는 컴퓨터의 폴더를 선택해 연결합니다.

### 📌 탭 고정

- 현재 탭 또는 최근 변경사항에서 더블 클릭 또는 길게 클릭시 탭 목록으로 고정됩니다.
- X 버튼을 눌러 고정을 해제할 수 있습니다.

### ⇄ 탭 순서 변경

- 탭 목록에서, 항목을 위아래로 드래그하여 순서를 자유롭게 변경할 수 있습니다.
- 변경된 순서는 즉시 반영되며 자동으로 저장됩니다. 자주 사용하는 노트를 상단에 배치하여 작업 효율을 높일 수 있습니다.

### 🔐 개인 액세스 토큰(PAT) 관리

- 외부 서비스 및 애플리케이션 연동에 필요한 개인 액세스 토큰(PAT)을 직접 생성하고 관리할 수 있습니다.
- 계정 수정 모달 내 전용 섹션에서 새 토큰을 발급받을 수 있으며, 보안을 위해 발급 직후 단 한 번만 토큰 값이 노출되므로 즉시 복사하여 안전한 곳에 보관해야 합니다.
- 현재 활성화된 토큰 목록과 만료일을 확인하고, 더 이상 사용하지 않는 토큰은 언제든지 삭제하여 보안을 유지할 수 있습니다.

## 확장 기능

### 🧩 자동 추출 템플릿

비슷한 노트의 공통 양식을 이용해 회의록이나 업무 기록 같은 새 노트를 작성할 수 있습니다.

1. **확장 기능 설정 → 자동 추출 템플릿**을 켜고 홈 메뉴 또는 사이드 메뉴에서 엽니다.
2. **찾은 템플릿**에서 양식을 선택해 미리봅니다. 원본을 비교하려면 **목록 아이콘(비슷한 노트)**을 누르고 노트를 선택합니다. 목록 아이콘을 다시 누르면 미리보기로 돌아갑니다.
3. **연필 아이콘(새 노트)**을 누릅니다. **제목 템플릿**을 선택해 날짜나 키워드를 채우거나, **제목 직접 입력**으로 제목을 작성합니다.
4. **내용 템플릿**에서 본문을 입력하고 **내용 미리보기**로 확인합니다. 두 화면을 전환해도 입력값은 유지됩니다.
5. **저장**을 누릅니다. 저장할 수 없는 경우 표시된 미입력 항목을 채우고, 같은 제목의 노트가 있으면 제목을 바꿉니다.

**입력과 원본 확인**

- `{{ 날짜 }}`, `{{ 키워드 }}`는 채울 입력 자리입니다. `*`가 붙은 제목 항목은 필수이며, 비워둔 본문 입력 자리는 그대로 남습니다. 같은 이름의 입력 자리는 입력값을 함께 사용합니다.
- 반복 행·열이 있는 표에서는 **＋ 행 / ＋ 열**로 항목을 추가하고 **×**로 삭제할 수 있습니다. 반복 열의 이름도 수정할 수 있습니다.
- 제목에 표시된 폴더 경로가 새 노트의 저장 위치입니다. 아직 없는 노트의 템플릿 태그에서 시작하면 해당 노트의 제목이 미리 입력됩니다.
- 노트 상단의 **템플릿 이름 태그**를 누르면 **비슷한 노트** 목록을 열 수 있습니다. 태그 이름이 짧게 표시되면 템플릿 화면에서 전체 이름을 확인하세요.
- 본문 전환 탭은 `Tab`으로 선택하고 `←` / `→`로 전환할 수 있습니다. 작성 중 템플릿 미리보기로 돌아가려면 이름 옆의 문서 아이콘을, 다른 템플릿을 고르려면 **‹ 목록**을 누릅니다.

템플릿이 보이지 않으면 비슷한 제목 구성이나 표 양식을 가진 노트가 두 개 이상 있는지 확인하세요. 저장 전 미리보기에서 새 노트의 내용을 확인하세요.

### ⚡ 퀵 메모 (Quick Memo)

- 특정 노트와 부모 문단을 선택하여 하위 문단을 즉시 추가할 수 있는 기능입니다.
- 가장 최근에 메모를 추가했던 노트와 문단 정보가 자동으로 저장되어, 다음번에 동일한 위치에 빠르게 기록할 수 있습니다.
- 상단의 exchange 아이콘을 눌러 메모를 추가할 대상(노트 및 문단)을 간편하게 변경할 수 있습니다.

### 🔍 노트 내용 검색

- 상단 검색창에 키워드를 입력한 뒤 🔍 버튼을 누르거나 Enter 키를 누르면 검색 화면으로 이동합니다. **검색** 탭에서 노트 제목과 본문을 검색할 수 있습니다.
- 키워드 없이 검색 페이지를 열면 검색창에 키워드를 입력하라는 안내가 표시됩니다.
- 결과 목록 끝까지 내리면 다음 검색 결과를 불러옵니다.

### 🧾 편집 제안

- 자동으로 감지된 오류나 문제가 있는 노트 목록을 표시합니다
- 감지된 문제는 다음과 같은 유형으로 분류되어 표시됩니다:

| 문제 유형                              | 설명                                                                                                                   |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Empty paragraph                        | 문단의 제목은 있으나 본문이 비어 있는 경우                                                                             |
| Empty list                             | 문단 내 목록이 비어 있는 경우                                                                                          |
| Duplicate paragraphs(...)              | 동일한 문단 제목이 반복된 경우                                                                                         |
| Duplicate contents(...)                | 동일한 내용이 문단 내에서 반복된 경우                                                                                  |
| Too high readability score: X > 3.0    | 읽기 난이도 점수가 기준치를 초과한 경우                                                                                |
| Unknown note link(...)                 | 존재하지 않는 노트로 연결된 링크가 있는 경우                                                                           |
| Empty parent note(...)                 | 상위 노트의 내용이 없는 경우                                                                                           |
| Unlinked note keyword: ...             | 내용에 다른 노트로 연결 가능한 키워드는 있지만 해당 키워드에 링크가 연결되지 않은 경우                                 |
| Unlinked note keyword: ... => ...(...) | 내용에 다른 노트로 연결 가능한 키워드는 있지만 해당 키워드에 링크가 연결되지 않은 경우(다른 노트에서 작성된 링크 포함) |
| Isolated note                          | 본문 내용은 있으나 해당 노트로 들어오는 경로(상위 노트, 역링크, 연결된 보드)가 하나도 없는 경우                        |

- 문단이 비어있거나 링크가 잘못 연결된 경우, 또는 중복된 내용이 있는 경우 자동으로 분류됩니다
- 해당 항목을 클릭하면 문제 위치로 바로 이동하여 수정할 수 있습니다

### 📆 타임라인

- 노트에 작성된 날짜를 기반으로 일정을 한눈에 확인할 수 있는 기능입니다
- 노트 편집시 🕒 버튼으로 지정된 날짜 형식을 사용할 수 있습니다
- 지원하는 날짜 형식은 다음과 같습니다:
  - `YYYY-MM`
  - `YYYY-MM-DD`
  - `YYYY-MM-DD/YYYY-MM-DD`
  - `MM/DD`
  - `MM/DD ~ MM/DD`
  - `YYYY/MM/DD`
  - `YYYY/MM/DD ~ YYYY/MM/DD`
  - `YYYY. M. D.`
  - `YYYY. M. D.~YYYY. M. D.`
- 타임라인 화면 상단의 날짜 선택 바 또는 달력에서 원하는 날짜를 선택하여 연결된 콘텐츠를 탐색할 수 있습니다
- 일정이 표시된 문단을 바로 확인하고 편집할 수 있습니다
- 각 노트별 현재 일정은 타이머 바 형태로 시각적으로 표현되어 현재 상태를 쉽게 파악할 수 있습니다
- 노트 페이지에 표시되는 **타이머 태그(예: `YYYY-MM-DD`)를 클릭**하면 날짜를 수정할 수 있는 버튼 메뉴가 확장됩니다
  위 메뉴를 통해 '+1일', '+1달', '기간 연장', '삭제' 등 일정을 빠르게 변경할 수 있습니다

### 🕸️ 지식 그래프

노트·보드·문단·카드·외부 링크의 연결을 살펴보고 원문을 열 수 있습니다. **설정 → 확장 기능 → 지식 그래프**를 켠 뒤 메뉴에서 **지식 그래프**를 엽니다.

- **이동과 검색**: 화면을 드래그해 이동하고 마우스 휠·손가락 확대/축소·확대 버튼으로 크기를 조절합니다. **노드 검색**은 현재 표시된 항목의 이름을 찾습니다. 결과를 선택하면 해당 위치와 상세정보를 볼 수 있습니다. **간격**으로 항목 사이 거리를 조절합니다.
- **항목 선택**: 항목을 누르면 연결과 출처를 확인할 수 있습니다. 연관 범위 **1·2**를 선택하면 가까운 연결을 중심으로 살펴보고, **전체**를 선택하면 전체 연결을 봅니다. 연결·출처 목록에서 원본을 열 수 있습니다.
- **표시 옵션**: **기본**, **문단**, **일반 외부 링크** 토글로 표시할 항목을 고릅니다. 키워드와 템플릿은 각각의 토글로 표시하며, **그래프 도구**로 도구를 접거나 펼칩니다.
- **키워드 및 관계**: 상단 버튼으로 분석 화면을 엽니다. 분석 후 같은 이름의 그래프 토글을 켜면 키워드·유형·관계를 함께 볼 수 있습니다. 관계 선은 **근거 충족** 기준을 만족하는 그룹에 표시하며, 전체 결과와 근거는 분석 화면에서 확인합니다.
- **찾은 템플릿**: **자동 추출 템플릿** 확장이 켜져 있으면 템플릿과 출처 연결을 표시할 수 있습니다. 템플릿이나 그룹을 선택해 관련 문서를 살펴보세요.
- **범례와 검증**: 하단 범례에서 항목·관계의 종류와 개수를 확인합니다. **검증 통과·검증 경고·검증 오류** 배지를 누르면 문제 목록이 열리고, 항목을 선택하면 해당 위치로 이동합니다.

빈 노트도 다른 노트의 참조나 상하위 연결에 필요한 경우 표시됩니다. 로컬 파일의 변경사항은 다음 자동 새로고침 때 반영됩니다.

#### 🔎 그래프 검색

1. 상단 검색창에 검색어를 입력한 뒤 **지식 그래프** 탭을 선택합니다.
2. 준비 안내가 나오면 **분석 시작**을 누릅니다. 준비가 끝나면 입력한 검색어로 자동 검색을 이어갑니다.
3. **연관 범위(N-hop)**로 탐색할 연결 범위를 조절합니다. 여러 항목 사이의 연결을 찾으려면 항목 이름을 함께 입력하세요.
4. **컨텍스트 크기**에서 16k·32k·64k·128k·256k 중 결과에 담을 분량을 선택합니다. 1k는 Markdown 원문 기준 1,000자이며, **컨텍스트 사용량**에서 사용한 분량과 한도를 확인할 수 있습니다.
5. 결과의 **검색 경로**, **연관 경로**, **연관 항목**, **인용된 본문**을 확인합니다. 인용 번호와 출처 링크로 근거를 읽거나 원본 노트·문단을 열 수 있습니다. 외부 링크는 항목 이름을 눌러 엽니다.

결과에는 선택한 범위와 크기에 따라 일부 내용이나 근거가 생략될 수 있으며, 생략 여부가 함께 표시됩니다. 원하는 연결이나 근거가 보이지 않으면 연관 범위나 컨텍스트 크기를 늘려 확인하세요. 그래프에서 숨긴 항목도 검색에는 포함됩니다.

인용 옆의 참조 링크로 연결된 원문도 확인할 수 있습니다. 검색 중에는 다른 컨텍스트 크기를 선택하거나 검색을 취소할 수 있습니다.

**검색 경로**는 질문 대상 사이의 연결을, **연관 경로**는 주변 항목으로 이어지는 연결을 보여줍니다. 경로는 시작점별 계층 목록으로 표시하며 공통 구간은 합칩니다. 같은 상위 항목에서 동일 항목으로 이어지는 여러 관계는 방향·인용 번호와 함께 나란히 표시합니다. 각 항목은 `(분류)`로 구분하며, 문단은 `(문단[노트명])`처럼 소속 노트도 표시합니다.

경로를 찾지 못했거나 크기 제한으로 생략한 경우에는 안내와 대상 목록을 확인하세요. 검색 경로 제목의 `(정상 경로 수/전체 수)`는 실제 목록에 표시된 정상 경로와 미발견·생략 대상만 셉니다. 미발견·생략 안내가 없으면 경로 수 `(n)`만 표시합니다. 선택한 범위에서 경로를 찾지 못해도 범위를 넓히면 연결을 찾을 수 있습니다.

#### 🏷️ 키워드 및 관계

현재 노트북에서 반복되는 키워드와 관계를 찾을 수 있습니다. 자동으로 찾은 결과는 출처 원문과 함께 확인하세요.

1. 지식 그래프 상단에서 **키워드 및 관계**를 엽니다.
2. **자동 사용 가능**이면 저장된 결과를 확인합니다. **생성 필요**이면 **분석 시작**, **갱신 필요**이면 **캐시 갱신**을 누릅니다. 오류는 **분석 안내**에서 확인합니다.
3. **키워드** 탭에서 이름을 검색하거나 **키워드 필터**를 펼쳐 결과를 좁힙니다. 키워드 이름을 누르면 **개체** 탭으로 이동합니다.
4. **개체** 탭에서 일반관계·출처 노트·연관관계를 확인합니다. **연관관계**에서는 개체쌍의 관계와 근거를 살펴봅니다. 카드 제목이나 화살표를 누르면 내용을 펼칠 수 있습니다.
5. 출처 노트나 문단 제목을 눌러 원문을 엽니다. 노트를 수정했다면 **노트 새로고침** 후 안내에 따라 **캐시 갱신**을 누릅니다. 분석이 끝나면 **다시 분석**할 수 있습니다.

화면을 이동해도 분석은 계속됩니다. 진행바에서 전체 진행률과 현재 단계의 처리 현황을 확인할 수 있습니다. 분석·검색 준비 중에는 **노트 새로고침**을 사용할 수 없습니다. 직접 중단하거나 노트북·계정·프라이빗 모드를 바꾸면 작업이 중단됩니다. 갱신이 중단되거나 실패해도 이전 저장 결과는 유지됩니다.

검색 준비가 느리면 개발자 콘솔의 `검색 준비: 처리 시간`을 확인하세요. 각 실행이 완료·실패·중단될 때 전체 시간, 5초 초과 여부, 관계 캐시 확인과 저장소 읽기부터 모델 준비까지의 세부 시간을 한 로그에 기록합니다.

검색 준비는 관계 분석과 병행하며 저장된 검색 자료를 재사용합니다. 준비가 끝나면 검색어나 연관 범위를 바꿔도 같은 자료를 다시 준비하지 않습니다.

성능 로그에는 검색 자료·색인 구성, 모델 파일 준비·첫 추론 시간을 구분해 기록합니다. `시작ms`가 음수이면 검색 준비 표시 이전부터 병행한 작업입니다.

검색 화면을 새로 열어도 원문·노트북 범위·루트 이름·언어가 같으면 완료된 템플릿 분석을 재사용합니다. 분석이 덜 반영된 자료로 완료된 검색 인덱스를 교체하지 않습니다. 256k를 포함한 큰 컨텍스트는 근거나 속성이 바뀐 항목과 관련 경로만 다시 계산하며, 인용 위치와 Markdown 크기 제한은 정확히 유지합니다.

분석·검색 캐시 키는 다른 저장 설정처럼 `접두사:계정ID:노트북ID:프라이빗모드` 형식을 사용합니다. 로컬 계정은 계정ID를 비우고 일반 노트는 노트북ID를 `0`으로 둡니다. 사용 모드는 키에 추가하지 않으며 새 형식의 키만 조회·저장합니다. 번역된 유형명은 해시로 비교합니다.

수집 캐시는 노트 제목·본문·인용문을 복사하는 대신 패턴 해시, 등장 구조와 현재 원문을 가리키는 위치 참조를 저장합니다. 재사용 시 이미 읽은 노트에서 한 번만 메모리로 복원하므로 키워드 추출·관계 수집을 반복하지 않습니다. 벡터 캐시는 모델 정보·해시 식별자·수치 임베딩만 저장하며 검색 텍스트는 메모리에 둡니다. 원문이나 규칙이 바뀌면 위치 참조는 무효화됩니다. 이 형식의 첫 사용 시 기존 원문 포함 수집 캐시를 제거하므로 분석을 한 번 다시 실행해야 하며, 기존 임베딩 벡터는 유지합니다.

키워드는 서로 다른 노트 **3개 이상**에서 반복되는 이름을 대상으로 찾습니다. 이름의 공통 부분에서 얻은 구성 키워드도 표시합니다. 예를 들어 `서울역`·`서울시청`·`서울버스`에서 `서울`을 찾을 수 있습니다.

**키워드 필터**에서 여러 항목을 고를 때 **OR**는 하나 이상, **AND**는 모두 만족하는 결과를 표시합니다. **전체**는 해당 필터의 제한을 해제하며, 필터를 접어도 선택은 계속 적용됩니다.

- **키워드 출처**: 노트·문단·참조·굵게 처리된 글·속성·속성값에서 고릅니다.
- **키워드 구성**: 복합키워드·포함키워드·합성키워드·구성키워드·없음에서 고릅니다. 다른 키워드를 이름 안에 포함하면 복합키워드, 그 안에 들어가는 키워드는 포함키워드입니다. 공통 부분에서 얻은 이름은 구성키워드, 이를 포함한 원래 키워드는 합성키워드입니다. 한 키워드가 여러 역할을 가질 수 있습니다.
- **개체 패턴**: 숫자 패턴·공통 접두 패턴·없음에서 고릅니다.
- **개체 유형**: 목록·제목·표 등에서 함께 반복된 항목을 묶은 유형입니다. 상위 유형을 고르면 하위 유형도 포함하며, **없음**으로 어느 유형에도 속하지 않는 키워드를 볼 수 있습니다.

**개체 → 일반관계**에서 유형·패턴 소속과 복합·포함 및 합성·구성 관계를 확인합니다. 이처럼 이미 일반관계로 연결된 쌍은 연관관계에 중복 표시하지 않습니다. **출처 노트**에서는 출처별로 결과를 좁히고 원문을 열 수 있습니다.

개체의 연관관계와 **연관관계**에는 다음 필터가 있습니다.

- **연관관계 유형**: 같은 문장·리스트 항목·표 행·표 셀·속성값 내 연관성, 속성을 통한 연관성을 고릅니다.
- **집계 기준**: **속성·표 열 조합·근거 묶음**에서 고릅니다.
- **그룹화 유형**: 개체 유형·개체 패턴·키워드 기준으로 묶인 결과를 고릅니다. **근거 충족**을 함께 선택하면 반복된 근거와 연관성 점수를 기준으로 결과를 좁힙니다.

서로 다른 필터는 함께 적용합니다. 연관관계 유형과 집계 기준의 **AND**는 같은 개체쌍에서 선택한 조건을 모두 만족해야 합니다. 카드를 펼치면 **연결 유형 → 집계 기준 → 원문 근거** 순으로 확인할 수 있습니다. 유형과 패턴은 `{{편집기}}`처럼 표시하고 키워드는 원래 이름으로 표시합니다. 결과가 많으면 **이전·다음**으로 페이지를 이동하세요.

**연관성 점수**는 연결의 강도이며 확률은 아닙니다. **일반화 점수**는 서로 다른 개체쌍·노트에서도 같은 관계가 반복되는 정도입니다. 구체적인 의미나 방향은 근거 원문으로 확인하세요. 평가하지 않은 결과는 **미평가**로 표시합니다.

### 📦 보관함 (백업 및 복원 기능)

- 모든 노트와 보드를 ZIP 아카이브 형식으로 백업할 수 있습니다.
  - **노트**는 Markdown (`.md`) 파일로 저장됩니다.
  - **보드** (칸반/스크럼 보드 옵션 및 설정 정보)는 구조화된 JSON (`.json`) 파일(예: `{보드 제목}.json`)로 저장됩니다.
- ZIP 아카이브, Markdown (`.md`) 파일, 보드 JSON (`.json`) 파일을 불러와 노트와 보드를 손쉽게 복원할 수 있습니다.

### 🎯 랜덤 노트 열람

- 랜덤 버튼을 통해 무작위로 노트를 열람하며 새로운 관점을 얻을 수 있습니다

### 📄 PDF 다운로드 (기본 스타일 - 인쇄 최적화)

- 현재 열람 중인 노트(또는 선택된 하위 문단)를 배경을 흰색으로, 글자색을 검은색으로 고정하고 인쇄에 최적화된 형태로 PDF 인쇄 또는 저장할 수 있는 기능입니다.
- 노트 열람 화면 상단의 인쇄 아이콘 버튼을 클릭하면 실행됩니다.

### 📄 PDF 다운로드 (현재 테마 스타일 - 테마 유지)

- 현재 노트북에 적용된 테마(다크 모드, 스킨 등)와 배경/텍스트 색상을 그대로 유지하여 PDF 문서로 변환하는 기능입니다.
- 노트 열람 화면 상단의 PDF 아이콘 버튼을 클릭하면 실행됩니다.

### 🔲 노트 본문만 보기 (집중 보기)

- 확장 기능 설정에서 활성화하여 사용할 수 있습니다.
- 노트 화면 상단의 '최대화' 아이콘을 클릭하여 상단 네비게이션, 검색바, 하단 목차 및 이동 버튼 등을 모두 숨기고 오직 노트 본문만 화면 가득 표시할 수 있습니다.
- 본문만 보기 모드에서는 우측 상단의 '복귀' 아이콘을 클릭하거나 키보드의 `Escape` 키를 눌러 언제든 일반 화면으로 돌아올 수 있습니다.

### 🔄 노트북 동기화 (로컬 계정 - 내 계정 동기화)

로컬 계정과 내 계정의 노트·보드를 동기화할 수 있습니다.

- 로그인한 상태에서 노트북 모드를 사용하면 사이드 메뉴와 탐색 탭의 동기화 버튼에 변경된 파일 수가 표시됩니다.
- 연결할 로컬 노트북이 없으면 안내에 따라 저장할 폴더를 선택합니다.
- 동기화 화면에서 변경 전후 내용을 비교하고 반영할 내용을 확인합니다. 스마트 동기화는 최신 수정본을 우선합니다.
- 양쪽에서 같은 노트를 수정한 경우 **로컬 계정 반영** 또는 **내 계정 반영**을 선택합니다.
- **자동 동기화**를 켜면 충돌이 없는 항목을 자동으로 반영합니다. 충돌한 항목은 직접 선택해야 합니다.
- 화면을 열거나 노트를 저장할 때 자동으로 변경을 확인할지 설정할 수 있습니다. 수동 새로고침으로도 최신 변경사항을 확인할 수 있습니다.
