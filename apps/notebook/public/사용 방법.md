# 📘 Blacktokki Notebook 사용자 가이드

**Blacktokki Notebook**은 마크다운 기반의 **지식 관리 및 시간 관리 도구**입니다. 사용자는 다양한 주제의 노트를 자유롭게 작성하고 구조화하며, 일정과 연결하여 추적할 수 있습니다. 모바일과 웹 환경에서 모두 사용할 수 있으며, **자기 주도 학습**, **업무 관리**, **지식 아카이빙**, **회고 기록** 등에 유용하게 활용할 수 있습니다.

## 주요 특징

- ✅ 마크다운 에디터를 통해 자유롭게 노트를 작성할 수 있습니다
- 📁 폴더와 하위 노트 구조로 내용을 계층적으로 정리할 수 있습니다
- 🧭 문단 제목을 기반으로 자동 생성되는 트리 뷰로 빠르게 탐색할 수 있습니다
- 🔍 제목과 문단 이름, 링크, 키워드까지 포함한 고급 검색 기능을 제공합니다
- 🔁 특정 문단을 다른 노트로 이동할 수 있습니다
- 📆 일정 정보를 자동으로 감지하여 타이머 형태로 시각화할 수 있습니다
- 🧠 자동완성 기능으로 링크와 자식 노트를 빠르게 작성할 수 있습니다
- 🧳 Markdown/JSON ZIP 아카이브 형식으로 노트와 보드를 내보내거나 다시 가져올 수 있습니다

## 시작하기 (Getting Started)

### 🔍 노트 검색 및 생성

- 상단 검색창에서 키워드 입력 시 기존 노트 탐색 및 새 노트 생성 가능
- 새로운 제목 입력 후 `Enter` 키를 누르면 자동으로 해당 노트 생성 및 진입

### ✏️ 노트 편집

- 마크다운 기반 에디터 제공
- 자동완성 트리거:
  - `[` → 내부 노트 링크. `[키워드` 입력 시 다른 노트 제목뿐만 아니라 **현재 노트의 문단 제목** 또는 **새로운 하위 노트(예: `현재노트/키워드`)** 생성을 제안합니다.
  - `http` → 외부 링크 미리보기

## 화면별 기본 사용법

### 🏠 홈

- 첫 진입 시 가장 먼저 보이는 메인 화면입니다
- 최근 열람한 노트 목록, 편집 제안, 타임라인 기능에 빠르게 접근할 수 있습니다
- 모바일 환경에서는 하단 탭으로 주요 메뉴에 접근하며, 웹에서는 좌측 메뉴(Drawer)를 통해 모든 기능에 빠르게 이동할 수 있습니다

### 📄 노트 페이지

- 노트의 제목과 본문, 그리고 구조화된 문단 목록이 함께 제공됩니다
- 사이드에 표시되는 문단 목록은 노트 내 제목(H1~H6)을 기반으로 자동 생성되며, 클릭 시 해당 위치로 이동합니다
- 상단 버튼을 통해 노트를 편집하거나, 문단 이동 또는 편집 이력을 확인할 수 있습니다

### ✏️ 노트 편집

- 위지윅/마크다운 형식으로 작성 가능한 에디터 화면입니다
- 노트의 본문을 자유롭게 작성하거나 수정할 수 있으며, 자동 저장 기능과 수동 저장 기능이 모두 제공됩니다
- 내부 노트 링크, 외부 링크 자동완성 기능을 활용할 수 있습니다

### 🗂 최근 노트

- 사용자가 가장 최근에 열람하거나 작성한 노트들을 카드 및 그리드 형태로 나열하여 보여줍니다
- 상단 우측의 뷰 모드 전환 아이콘을 클릭하여 하위 노트 목록, 칸반 보드, 스크럼 보드 등 다양한 보기 모드로 직관적으로 전환할 수 있습니다 (단, 간단 모드에서는 하위 노트 목록 모드로 고정됩니다)
- 클릭 시 해당 노트로 바로 이동하며, 원하지 않는 노트는 리스트에서 제거할 수 있습니다

## 사용 모드 (Usage Mode)

사용자의 작업 스타일과 목적에 맞춰 앱의 복잡도와 제공되는 기능을 3단계로 조절할 수 있습니다.

- **헤더 드롭다운 메뉴 (빠른 전환):** 상단 네비게이션 헤더의 앱/노트북 제목을 클릭하여 열리는 드롭다운 팝오버를 통해 등록된 노트북 간 전환, 새 노트북 모드 추가, 또는 노트 모드로의 빠른 복귀 및 노트북 설정을 손쉽게 관리할 수 있습니다.
- **설정 메뉴:** `설정 > 노트 설정 > 모드 설정`에서도 사용 모드를 변경하고 관리할 수 있습니다. 생성된 노트북 모드가 없을 때 노트북 모드를 선택하면 새 노트북을 생성할 수 있는 모달이 자동으로 열립니다.

### 🌱 간단 모드 (Simple Mode)

최소한의 필수 기능만 제공하는 가장 가벼운 메모 환경입니다. 빠른 메모 작성과 열람에 집중하고 싶을 때 유용하며, 불필요한 UI(확장 기능, 변경내역 등)가 숨겨집니다.

### 📝 노트 모드 (Note Mode)

보드 기능이나 프라이빗 기능 없이 순수하게 문서 작성 및 지식 관리에 집중할 수 있는 기능들을 제공합니다. 본격적인 정보 구조화, 확장 기능 활용이 필요한 사용자에게 적합합니다.

- **🗃 아카이브**
  - 저장된 노트의 이전 버전(스냅샷)을 확인할 수 있는 화면입니다
  - 노트 제목별로 과거 저장 시점의 내용을 시간순으로 비교할 수 있습니다
  - 버전 관리와 과거 내용 복원이 필요할 때 유용하게 사용됩니다

### 📓 노트북 모드 (Notebook Mode)

앱이 제공하는 기능을 목적에 맞는 '노트북' 단위로 나누어 사용할 수 있는 환경입니다. 각 노트북 생성 시 일반 워크스페이스, 프라이빗 워크스페이스, 프라이빗 노트 등의 하위 모드를 지정하여 독립된 공간으로 격리하여 사용할 수 있습니다.

- **헤더 드롭다운을 통한 노트북 관리:**

  - 상단 헤더의 노트북 이름을 클릭하면 현재 등록된 노트북 목록이 표시되며, 원하는 노트북을 선택해 즉시 작업 공간을 전환할 수 있습니다.
  - 노트북 항목 우측의 메뉴(⋮) 버튼을 눌러 노트북의 제목, 설명, 하위 모드 등 설정을 수정하거나 삭제할 수 있습니다. 현재 접속 중인 노트북 모드를 삭제하면 자동으로 기본 노트 모드로 복귀합니다.
  - `+ 새 노트북 모드 추가` 버튼으로 새로운 노트북을 손쉽게 생성할 수 있고, `〈 노트 모드로 변경` 버튼으로 기본 노트 모드로 빠르게 복귀할 수 있습니다.

- **🗂 일반 워크스페이스 (Workspace)**

  - 노트의 문단들을 칸반/스크럼 보드 형태로 시각화하고 관리할 수 있는 기능이 포함된 노트북입니다.
  - 메모와 문서 관리를 넘어 프로젝트 및 일정 관리까지 병행할 때 추천합니다.

- **🔐 프라이빗 노트 & 워크스페이스 (Private)**
  - 공개적인 장소에서 노트를 열람하거나 화면 공유 시, 민감한 정보를 숨길 수 있는 노트북 타입입니다.
  - **프라이빗 모드 통합 관리:** 노트북 모드 선택 후 나타나는 프라이빗 모드(On/Off) 토글을 통해 모든 프라이빗 노트북의 잠금을 한 번에 관리할 수 있습니다.
  - **보안 강화 (OTP 인증):** '프라이빗 모드 진입 시 OTP 요구' 옵션을 활성화하면, 모드에 진입하거나 해당 보안 설정을 해제할 때 OTP 인증 모달을 통한 추가 검증을 수행합니다. (온라인 계정 및 OTP 활성 상태에서 지원)
  - **자동 해제 타이머:** '10분 미사용 시 자동 해제' 옵션을 켜두면, 마지막 활동 이후 10분간 조작이 없을 경우 프라이빗 모드가 자동으로 비활성화됩니다.
  - 모드가 꺼진(Off) 상태에서 URL 등을 통해 숨겨진 노트에 직접 접근할 경우, 경고 문구가 표시되며 내용을 볼 수 없습니다.

#### 🗂 보드

> 워크스페이스 타입 공통 기능

- 노트의 문단들을 칸반/스크럼 보드 형태로 시각화하고 관리할 수 있는 기능입니다.
- **아이콘 기반 뷰 모드 전환:** 최근 노트(RecentPages) 화면 상단 우측의 아이콘 버튼을 통해 하위 노트 목록 뷰, 칸반 보드, 스크럼 보드, 보드 설정을 직관적으로 전환하거나 생성할 수 있으며, 노트 화면 제목 좌측의 보드로 이동 아이콘을 통해 상위 보드로 쉽게 이동할 수 있습니다.
- **컬럼 이름순 정렬:** 칸반 및 스크럼 보드에서 컬럼(열) 역할을 하는 직계 하위 노트들은 수정 시간순이 아닌 **이름순(자연 문자열 정렬, 숫자 프리픽스 지원)**으로 고정 정렬되므로, 카드 수정이나 이동 시에도 컬럼의 순서가 뒤바뀌지 않고 안정적으로 유지됩니다.
- 각 보드의 '컬럼(Column)'은 사용자가 지정한 **개별 노트**로 구성됩니다. (예: 'To Do' 노트, 'In Progress' 노트)
- 각 컬럼의 '카드(Card)'는 해당 노트 내의 **특정 레벨 제목(예: H2, H3)을 가진 문단**들로 자동 구성됩니다. (보드 설정에서 헤더 레벨 지정 가능)
- **스크럼 보드**에서는 카드 기준 헤더의 상위 레벨(Header Level - 1)을 기준으로 **행(Row)**이 자동 생성되어, 프로젝트의 단계나 담당자별로 카드를 더 입체적으로 구조화할 수 있습니다.
- 카드를 드래그 앤 드롭하여 다른 컬럼으로 이동시킬 수 있습니다.
- 카드를 다른 컬럼으로 이동시키면, 해당 문단의 내용이 실제로 다른 노트로 이동됩니다. (예: 'To Do' 노트의 H3 문단을 'In Progress' 노트로 이동)
- 카드를 **한 번 클릭(탭)**하면 해당 문단을 읽을 수 있는 노트 화면으로 이동하며, **더블 클릭(더블 탭)**하면 즉시 내용을 수정할 수 있는 편집 화면으로 진입합니다.
- **빈 노트/카드 안내 개선:** 내용이 없는 빈 노트나 카드를 표시할 때 직관적인 아이콘과 노트 제목을 안내하며, 빈 노트 접근 시 편집하기 및 보드 생성 버튼을 함께 제공합니다 (간단 모드 제외).

## 고급 기능

### 📝 듀얼 에디터 지원

- 노트 편집 화면은 `M↓` 버튼으로 WYSIWYG 방식과 마크다운 방식 두 가지 모두를 자유롭게 변환할 수 있습니다.
- 두 편집 방식은 실시간으로 동기화되어 한쪽을 수정하면 다른 쪽에서도 바로 반영됩니다
- 사용자는 마크다운에 익숙하든, 시각적인 편집을 선호하든 모두 편리하게 작성할 수 있습니다

### 🏷️ YAML Frontmatter 보존 및 메타데이터 지원

- 마크다운 문서 최상단에 작성된 **YAML Frontmatter(`--- ... ---`)** 메타데이터 블록을 자동으로 인식하고 보호합니다.
- 시각적 에디터(WYSIWYG) 모드에서는 편집 중 실수로 변형되지 않도록 숨김 처리되며, 마크다운 모드 변환이나 파일 저장/아카이브 내보내기 시 원본 그대로 100% 보존됩니다.
- 다른 마크다운 편집기(Obsidian, Jekyll 등)에서 작성한 메타데이터가 포함된 문서를 그대로 가져와도 손실 없이 관리할 수 있습니다.

### 📑 문단 구조 자동 인식

- 노트에 작성된 제목은 자동으로 문단 구조로 변환되어 트리 형태로 표시됩니다
- 사용자는 이 트리를 통해 특정 문단으로 바로 이동하거나 전체 구조를 시각적으로 파악할 수 있습니다

### ⌞⌝ 문단 내용 전체 보기 기능

- 특정 문단으로 이동했을 때, 상단의 '펼치기' / '접기' 아이콘을 통해 해당 문단의 내용만 볼지, 하위 문단들의 내용까지 포함해서 볼지 토글할 수 있습니다.
- 하위 문단을 포함해서 보는 경우(펼치기), 해당 문단의 제목부터 모든 하위 문단의 내용이 하나의 노트처럼 표시됩니다.

### 🔗 링크 인식 및 연결

- 노트 내 삽입된 링크는 자동으로 인식되어 다른 노트 또는 외부 웹 페이지로 연결됩니다
- 다른 노트로 연결되는 링크는 검색이나 자동완성 결과에서 추천 항목으로 표시됩니다

### ⏱ 노트별 일정 자동 감지

- 타임라인에서 지원하는 날짜 형식으로 각 노트에서 작성된 일정을 자동으로 표시합니다
- 각 노트별 현재 일정은 타이머 바 형태로 시각적으로 표현되어 현재 상태를 쉽게 파악할 수 있습니다

### 🔍 검색 기록과 자동완성

- 검색한 키워드는 자동으로 저장되어 다음 검색 시 추천 항목으로 활용됩니다
- 최근 사용한 키워드를 빠르게 불러와 반복 입력을 줄일 수 있습니다

### 🔄 노트 및 문단 이동 (재배치)

- 전체 노트 또는 특정 문단을 다른 제목이나 위치로 이동하여 지식 구조를 재정비할 수 있습니다.
- **하위 노트 포함 이동**: 상위 노트의 이름이나 위치를 변경할 때, 해당 노트에 속한 모든 하위 노트를 한 번에 이동시킬 수 있습니다.
- **역링크 업데이트**: 이동 대상인 노트나 문단을 참조하고 있는 다른 노트들의 내부 링크(역링크)를 찾아 새 경로로 일괄 자동 업데이트하여 연결 끊김을 방지합니다.
- **변경사항 미리보기**: 이동 전 구조 변경 내용과 텍스트의 변경점(Diff)을 미리보기로 확인하여 안전하게 편집할 수 있으며, 이동하려는 대상 노트가 이미 존재할 경우 경고를 확인하고 덮어쓸 수 있습니다.

### 💾 저장 방식과 계정 연결

- 로컬 계정 또는 외부 계정을 선택하여 사용할 수 있으며, 계정에 따라 저장 위치가 달라집니다
- 온라인 상태에서는 자동 동기화가 활성화되어 최신 상태가 유지됩니다
- 로컬 계정의 노트·간단 모드는 별도 설정 없이 브라우저 내부 스토리지(OPFS)에 데이터가 자동 저장됩니다
- 로컬 계정의 노트북 모드는 내 컴퓨터의 로컬 폴더를 직접 선택하여 연동하며, 권한 정보는 브라우저(IndexedDB)에 유지됩니다

### 📌 탭 고정

- 현재 탭 또는 최근 변경사항에서 더블 클릭 또는 길게 클릭시 탭 목록으로 고정됩니다.
- X 버튼을 눌러 고정을 해제할 수 있습니다.

### ⇄ 탭 순서 변경

- 탭 목록에서, 항목을 위아래로 드래그하여 순서를 자유롭게 변경할 수 있습니다.
- 변경된 순서는 즉시 반영되며 자동으로 저장됩니다. 자주 사용하는 노트를 상단에 배치하여 작업 효율을 높일 수 있습니다.

### 🔐 개인 액세스 토큰(PAT) 관리

- 외부 서비스 및 애플리케이션 연동에 필요한 개인 액세스 토큰(PAT)을 직접 생성하고 관리할 수 있습니다.
- 계정 수정 모달 내 전용 섹션에서 새 토큰을 발급받을 수 있으며, 보안을 위해 발급 직후 단 한 번만 토큰 값이 노출되므로 즉시 복사하여 안전한 곳에 보관해야 합니다.
- 현재 활성화된 토큰 목록과 만료일을 확인하고, 더 이상 사용하지 않는 토큰은 언제든지 삭제하여 보안을 유지할 수 있습니다.

## 확장 기능

### ⚡ 퀵 메모 (Quick Memo)

- 특정 노트와 부모 문단을 선택하여 하위 문단을 즉시 추가할 수 있는 기능입니다.
- 가장 최근에 메모를 추가했던 노트와 문단 정보가 자동으로 저장되어, 다음번에 동일한 위치에 빠르게 기록할 수 있습니다.
- 상단의 exchange 아이콘을 눌러 메모를 추가할 대상(노트 및 문단)을 간편하게 변경할 수 있습니다.

### 🔍 노트 내용 검색

- 상단 검색창에 키워드 입력 후 🔍 버튼을 누르거나 Enter 키를 누르면 노트 제목뿐만 아니라 본문 내용까지 검색하는 검색 결과 페이지로 이동합니다.

### 🧾 편집 제안

- 자동으로 감지된 오류나 문제가 있는 노트 목록을 표시합니다
- 감지된 문제는 다음과 같은 유형으로 분류되어 표시됩니다:

| 문제 유형                              | 설명                                                                                                                   |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Empty paragraph                        | 문단의 제목은 있으나 본문이 비어 있는 경우                                                                             |
| Empty list                             | 문단 내 목록이 비어 있는 경우                                                                                          |
| Duplicate paragraphs(...)              | 동일한 문단 제목이 반복된 경우                                                                                         |
| Duplicate contents(...)                | 동일한 내용이 문단 내에서 반복된 경우                                                                                  |
| Too high readability score: X > 3.0    | 읽기 난이도 점수가 기준치를 초과한 경우                                                                                |
| Unknown note link(...)                 | 존재하지 않는 노트로 연결된 링크가 있는 경우                                                                           |
| Empty parent note(...)                 | 상위 노트의 내용이 없는 경우                                                                                           |
| Unlinked note keyword: ...             | 내용에 다른 노트로 연결 가능한 키워드는 있지만 해당 키워드에 링크가 연결되지 않은 경우                                 |
| Unlinked note keyword: ... => ...(...) | 내용에 다른 노트로 연결 가능한 키워드는 있지만 해당 키워드에 링크가 연결되지 않은 경우(다른 노트에서 작성된 링크 포함) |
| Isolated note                          | 본문 내용은 있으나 해당 노트로 들어오는 경로(상위 노트, 역링크, 연결된 보드)가 하나도 없는 경우                        |

- 문단이 비어있거나 링크가 잘못 연결된 경우, 또는 중복된 내용이 있는 경우 자동으로 분류됩니다
- 해당 항목을 클릭하면 문제 위치로 바로 이동하여 수정할 수 있습니다

### 📆 타임라인

- 노트에 작성된 날짜를 기반으로 일정을 한눈에 확인할 수 있는 기능입니다
- 노트 편집시 🕒 버튼으로 지정된 날짜 형식을 사용할 수 있습니다
- 지원하는 날짜 형식은 다음과 같습니다:
  - `YYYY-MM`
  - `YYYY-MM-DD`
  - `YYYY-MM-DD/YYYY-MM-DD`
  - `MM/DD`
  - `MM/DD ~ MM/DD`
  - `YYYY/MM/DD`
  - `YYYY/MM/DD ~ YYYY/MM/DD`
  - `YYYY. M. D.`
  - `YYYY. M. D.~YYYY. M. D.`
- 타임라인 화면 상단의 날짜 선택 바 또는 달력에서 원하는 날짜를 선택하여 연결된 콘텐츠를 탐색할 수 있습니다
- 일정이 표시된 문단을 바로 확인하고 편집할 수 있습니다
- 각 노트별 현재 일정은 타이머 바 형태로 시각적으로 표현되어 현재 상태를 쉽게 파악할 수 있습니다
- 노트 페이지에 표시되는 **타이머 태그(예: `YYYY-MM-DD`)를 클릭**하면 날짜를 수정할 수 있는 버튼 메뉴가 확장됩니다
  위 메뉴를 통해 '+1일', '+1달', '기간 연장', '삭제' 등 일정을 빠르게 변경할 수 있습니다

### 🕸️ 온톨로지

- 노트북 내의 지식 베이스를 VOWL(Visual Notation for OWL Ontologies)에서 영감을 받은 온톨로지 그래프로 시각화합니다:
  - **1. 클래스 (Class - 원형 노드)**:
    지식 베이스의 개체들을 범주별로 분류하고 상속(`subClassOf`) 구조로 체계화합니다:
    - **기본 클래스 계층 (Built-in Class - 파란색)**:
      - **`노트 클래스 (Note Class)`**: 일반 노트를 추상화하는 단일 기본 클래스입니다. 모든 일반 노트 인스턴스가 이 클래스에 속합니다.
      - **`링크로 연결된 문단 (Connected Paragraph Class)`**: 문서 간 방향성 링크(`references`)의 출발점 또는 도착 대상이 된 문단 인스턴스를 분류하는 기본 클래스입니다.
    - **보드 클래스 계층 (Board Class - 초록색)**:
      - **`보드 카드 클래스 (Board Card Class)`**: 각 보드 단위의 최상위 카드 추상 클래스입니다.
        - ↳ **`보드 카드 상태 서브클래스 (Board Card Status Subclass)`**: 보드 카드 클래스를 상속(`subClassOf`)하는 하위 클래스로, 보드의 상태(컬럼)별로 `{보드 이름}: {상태 이름}` 형식으로 정의됩니다. 보드의 각 카드 인스턴스는 해당 상태 서브클래스로부터 실체화(`instanceOf`)됩니다.
    - **주제 클래스 계층 (Topic Class - 자홍색)**:
      - **`주제: {키워드} (Generic Topic Superclass)`**: 노트 제목, 카드 유형, 헤더 구분을 통합하는 최상위 공통 주제 클래스입니다. 직계 하위 클래스 수와 직접 소속 출처 노트 수의 합이 3개 이상이거나 직계 하위 클래스 수가 2개 이상일 때만 생성되며, 같은 노트에서 나온 여러 문단·카드는 출처 노트 1개로 집계합니다.
        - ↳ **`노트 제목: {키워드}`**: 여러 노트 제목의 마지막 경로(`/` 제외)에서 공통으로 발견된 키워드를 상위 주제 클래스의 서브클래스(`subClassOf`)로 분류하며, 하위 인스턴스 합이 3개 이상일 때 생성됩니다.
        - ↳ **`카드유형: {부모 헤더 제목}`**: 카드와 가장 가까운 부모 헤더 제목을 바탕으로 분류하는 서브클래스(`subClassOf`)이며, 카드 인스턴스가 직접 연결됩니다. (해당 부모 헤더는 일반 헤더 제목 클래스 후보에서 제외됩니다.)
        - ↳ **`H{N} 제목: {키워드}`**: 같은 헤딩 레벨(H1~H6)에서 서로 다른 3개 이상의 노트에 걸쳐 공통 등장하는 헤더 제목 키워드를 상위 주제 클래스의 서브클래스(`subClassOf`)로 분류합니다.
      - _규칙_: 숫자만 포함된 키워드로는 주제 클래스를 생성하지 않으며, 동일 키워드의 세부 클래스가 존재할 경우 인스턴스를 중복 연결하지 않고 세부 클래스를 `subClassOf` 관계로 연결하여 다형적 추론을 가능하게 합니다.
  - **2. 인스턴스 (Instance - 원형 노드)**:
    - **노트 인스턴스 (파란색 이중 원형)**: 범례와 프리뷰에서 `인스턴스 (노트)`로 표시되는 독립 일반 노트 개체입니다.
    - **카드 인스턴스 (초록색 원형)**: 보드 상태 서브클래스로부터 실체화된 개체 문단(Card)입니다.
    - **문단 인스턴스 (보라색 원형)**: 가장 가까운 부모 문단이 있으면 그 문단에, 없으면 소속 노트에 하나의 계층 귀속 관계(`partOf`)로 연결되며, 상단 문단 토글로 표시 여부를 변경할 수 있습니다.
    - **연결된 문단 인스턴스 (주황색 원형)**: 참조 관계가 있거나 제목 키워드 클래스에 직접 연결된 문단입니다. 일반 문단과 같은 계층형 `partOf`를 유지하면서 상위 문단이 있으면 소속 노트에 점선 `connectedPartOf` 관계를 추가하며, 일반 문단 토글과 관계없이 표시됩니다. 실제 `references` 관계의 출발 또는 도착 문단은 `링크로 연결된 문단` 클래스에 속합니다. 제목 키워드 클래스로만 연결된 문단은 해당 제목 키워드 클래스 소속을 유지하며 `링크로 연결된 문단` 클래스에는 추가하지 않습니다.
  - **3. 속성 (Property - 일정·목차 내재화 및 리터럴 사각형)**:
    - 노드의 내부 데이터 속성 및 리터럴 노드(노란색 사각형)로 관리됩니다:
      - **일정 (Schedule)**: 타이머 태그 날짜 (예: `YYYY-MM-DD`)
      - **하위 섹션 (Sections)**: 카드의 하위 헤더 및 노트의 세부 헤더들이 구조적 데이터 속성으로 내재화되어 프리뷰 시트의 목차 칩으로 제공되며, 클릭 시 해당 문단 위치로 바로 이동합니다.
  - **4. 관계 (Relation - 방향성 엣지)**:
    - **`subClassOf` (파란색 화살표)**: 하위 서브클래스가 상위 클래스를 상속하는 계층 관계 (보드 상태 서브클래스 → 보드 카드 클래스, 특화 주제 서브클래스 → 주제 상위 클래스)
    - **`instanceOf` (파란 점선/실선 화살표)**: 인스턴스가 해당 클래스로부터 실체화됨을 나타내는 관계
    - **`references` (파란색 화살표)**: 문서 본문의 방향성 링크 관계(`_NOTELINK`)입니다. 링크가 문단 또는 카드 본문에 있으면 출발 노드로 해당 문단 또는 카드를 사용하고, 대상 문단이 지정되면 대상 노트보다 문단을 우선 연결합니다.
    - **`notePartOf` (회색 화살표)**: 하위 노트가 상위 노트에 귀속되는 `partOf` 구조 관계
    - **`cardPartOf` (노란색 화살표)**: 카드가 가장 가까운 상위 문단 또는 소속 노트에 귀속되는 `partOf` 구조 관계
    - **`paragraphPartOf` (노란색 화살표)**: 문단이 가장 가까운 상위 문단 또는 소속 노트에 귀속되는 `partOf` 구조 관계
    - **`connectedPartOf` (주황색 점선 화살표)**: 상위 문단이 있는 연결된 문단을 소속 노트에도 직접 연결하는 특수 `partOf` 관계
    - **추론 관계 (보라색 점선 화살표)**: 간접 추론 토글을 켜면 논리적인 클래스 상속과 상속된 인스턴스 소속을 표시합니다.
    - 하단 범례는 노드 항목을 첫째 행에, 현재 화면의 관계와 유형별 개수를 둘째 행에 표시합니다. 기본·보드·주제 클래스의 색상과 개수를 별도로 표시하고 노트 인스턴스를 카드 인스턴스보다 먼저 표시합니다. 상단 보기 토글은 `문단` → `속성(VOWL)` 순으로 배치됩니다.
  - **5. 검증 및 추론**:
    - **애플리케이션 참조 무결성 검증 (Broken Link Detection)**: 존재하지 않는 노트나 문단을 가리키는 링크를 감지합니다. 이는 범위가 한정된 애플리케이션 검증이며 전체 OWL 정합성 증명을 의미하지 않습니다.
    - 상단 **검증 HUD 배지**(`검증 통과`, `검증 경고`, `검증 오류`)를 클릭하여 상세 결과를 확인하고 연관된 노드를 즉시 탐색할 수 있습니다.
- 본문 내용이 없는 독립 노트는 그래프와 주제 키워드 클래스의 후보 계산에서 자동으로 제외됩니다. 다만 내용이 있는 노트가 참조하거나 상위 구조로 필요로 하는 기존 빈 노트는 골격 노트 인스턴스로 유지하되 주제 후보에서는 제외합니다. 이 골격 노트를 향한 노트 단위 링크는 유효하지만, 문단이 없으므로 특정 문단 링크는 무효입니다. 내용이 있는 보드 열 문단의 소속을 보장하는 보드 노트는 구조적 부모로 유지되며 노트 제목 기반 주제 후보에도 포함됩니다.
- 보드와 같은 이름의 노트 인스턴스 및 문단은 실제 노트 본문만 사용합니다. 보드 설정의 설명은 노트 문단으로 해석하지 않으며, 보드 컬럼의 문단은 보드 루트가 아닌 실제 컬럼 노트 인스턴스에 귀속됩니다.
- 노드를 탭하면 하단 프리뷰 시트가 열려 데이터 속성, 연관 관계 수, N-hop 필터를 확인할 수 있습니다. 인스턴스는 직접 소속된 클래스만 표시합니다. 클래스는 직접 부모 클래스와 자신을 직접 상속 중인 하위 클래스를 각각 표시하며 상위·하위의 다음 단계는 펼치지 않습니다. 클래스 배지를 누르면 해당 클래스의 상세정보로 전환됩니다. 노트 인스턴스에는 하위 섹션(목차)을 표시하지 않고 제목 키워드 클래스에는 원본 노트로 이동하는 버튼을 표시하지 않습니다.
- **주제 가상노트 (Topic Virtual Note)**: 동일한 이름의 실제 노트가 존재하지 않는 상위 주제클래스(Generic Topic Superclass) 또는 단독 특화 주제클래스에는 지식 그래프 상에 🪐 외곽 링이 표시되고 프리뷰 시트에 `[🪐 가상노트 열기]` 버튼이 제공됩니다. 클릭하면 해당 주제에 흩어진 문단·카드·하위 분류·출처 노트를 실시간 색인한 마크다운 가상노트가 열리며, 별도의 `주제 하위 분류별 지식` 절은 생성하지 않습니다. 다른 최상위 주제는 `공유 지식 수 + 공유 출처 노트 수`가 3 이상일 때만 연관 주제로 표시합니다. 명시적 참조는 기준 합계에 포함하지 않고 기준을 통과한 연관 주제의 보조 근거로만 표시합니다. 같은 기준으로 계산한 연관 주제 수를 주제 목록 요약과 가상노트 모달 상단 통계에 함께 표시합니다. 동명의 실제 노트가 있으면 실제 노트로, 없으면 해당 주제의 가상노트로 이동합니다. 본문 복사 및 **[실제 일반 노트로 저장]** 버튼을 통해 영구 보관할 수 있는 정식 일반 노트로 원클릭 저장할 수 있습니다. 이미 동명의 실제 노트가 있는 주제는 일반 노트 이동 대상이 되므로 가상노트 생성 대상에서 자동으로 제외됩니다.
- **온톨로지 주제 스크린 (Ontology Topic Screen)**: 상위 주제클래스 및 단독 특화 주제클래스를 목록(`NoteListSection`) 형태로 나열하여 한눈에 조망할 수 있는 전용 화면입니다. 상단 툴바의 전환 버튼을 통해 온톨로지 그래프 뷰와 주제 목록 화면 간을 자유롭게 이동할 수 있습니다. 목록의 항목을 클릭하면 동일 이름의 실제 노트가 있는 경우 해당 노트(`NotePage`)로 바로 이동하고, 실제 노트가 없는 경우 실시간 종합된 가상노트 뷰어(`VirtualNoteModal`)가 열려 열람 및 저장을 수행할 수 있습니다.
- 마우스 커서 중심 줌, 트랙패드 핀치 줌, 캔버스 드래그 및 자동 화면 맞춤을 지원합니다. 전체 노드 밀집도는 간격 조절값을 따르면서 각 주제 계층은 최상위 주제 클래스를 중심으로 더 조밀하게 배치됩니다. 간격 및 크기 조절 UI는 화면 폭이 충분하면 우측 상단에 여백 없이 정렬하고, 좁은 화면에서는 상단 보기 토글 아래에 배치하여 하단 범례나 상세정보와 겹치지 않게 표시합니다.
- **RDF 내보내기** 버튼을 누르면 현재 노트북의 클래스, 인스턴스, 관계, 속성, 애플리케이션 검증 결과, 추론 근거를 RDF 1.1 Turtle(`.ttl`) 파일로 추출합니다. 주제 클래스 ID는 정규화한 키워드와 범위로 결정되어 구성원이 추가되거나 삭제되어도 IRI가 바뀌지 않습니다. 제목 키워드 클래스는 클래스 범주인 `TopicClass`의 인스턴스이면서 `KnowledgeItem`의 하위 클래스로 내보내므로, 그 구성원이 별도의 `Topic` 개체로 오해되지 않습니다. 카드와 문단은 자체 제목·문단 경로·계층 소속을 내보냅니다. 검증 보고서는 독립 SHACL 재계산 결과가 아니라 현재 애플리케이션 검증의 스냅샷입니다. 의미 프로필은 RDFS 추론과 일부 OWL·SHACL·Dublin Core·PROV-O 어휘를 사용하는 RDF 1.1 그래프이며, 결합 내보내기는 OWL 2 DL 적합성을 주장하지 않습니다. 리소스 식별자는 배포 주소에 의존하지 않는 `urn:blacktokki:notebook:` IRI를 사용합니다. 웹에서는 파일을 다운로드하고 모바일 앱에서는 시스템 공유 화면을 엽니다.

### 📦 보관함 (백업 및 복원 기능)

- 모든 노트와 보드를 ZIP 아카이브 형식으로 백업할 수 있습니다.
  - **노트**는 Markdown (`.md`) 파일로 저장됩니다.
  - **보드** (칸반/스크럼 보드 옵션 및 설정 정보)는 구조화된 JSON (`.json`) 파일(예: `{보드 제목}.json`)로 저장됩니다.
- ZIP 아카이브, Markdown (`.md`) 파일, 보드 JSON (`.json`) 파일을 불러와 노트와 보드를 손쉽게 복원할 수 있습니다.

### 🎯 랜덤 노트 열람

- 랜덤 버튼을 통해 무작위로 노트를 열람하며 새로운 관점을 얻을 수 있습니다

### 📄 PDF 다운로드 (기본 스타일 - 인쇄 최적화)

- 현재 열람 중인 노트(또는 선택된 하위 문단)를 배경을 흰색으로, 글자색을 검은색으로 고정하고 인쇄에 최적화된 형태로 PDF 인쇄 또는 저장할 수 있는 기능입니다.
- 노트 열람 화면 상단의 인쇄 아이콘 버튼을 클릭하면 실행됩니다.

### 📄 PDF 다운로드 (현재 테마 스타일 - 테마 유지)

- 현재 노트북에 적용된 테마(다크 모드, 스킨 등)와 배경/텍스트 색상을 그대로 유지하여 PDF 문서로 변환하는 기능입니다.
- 노트 열람 화면 상단의 PDF 아이콘 버튼을 클릭하면 실행됩니다.

### 🔄 노트북 동기화 (로컬 계정 - 내 계정 동기화)

- 로컬 계정과 내 계정 간의 노트(`.md`) 및 보드(`.json`) 파일을 양방향으로 동기화합니다.
- **자동 매칭 및 배지 표시**: 로그인된 상태에서 노트북 모드로 접속 시, Drawer 및 Discovery 탭의 동기화 버튼에 변경·추가되었거나 차이가 존재하는 파일의 수가 배지(`CountBadge`)로 표시됩니다.
- **로컬 노트북 생성 및 폴더 연결**: 로컬에 동일한 이름의 노트북이 없는 경우, 동기화 진행 시점에 기존 노트북 생성 모달이 열려 계정 노트북 정보가 자동 입력된 상태로 실제 PC 저장 폴더를 지정할 수 있으며, 폴더 지정 완료 후 동기화가 이어서 자동으로 진행됩니다.
- **시각적 차이 비교 및 스마트 동기화**: 동기화 화면에서 변경된 노트의 텍스트 차이점을 시각적으로 비교하고 최신 수정본을 우선으로 하는 스마트 동기화를 안전하게 수행할 수 있습니다. (보드 설정도 함께 동기화됩니다.)
- **동시 편집(충돌) 탐지 및 선택 반영**: 로컬 계정과 내 계정 양쪽에서 동시에 수정된 노트(충돌)가 발생한 경우, 충돌 상태로 분류되어 사용자가 각 충돌 카드에서 [로컬 계정 반영] 또는 [내 계정 반영] 중 하나를 직접 선택하여 안전하게 병합할 수 있습니다.
- **자동 동기화(미충돌 노트)**: 동기화 화면에서 '자동 동기화' 옵션을 켜면, 충돌이 발생하지 않은 항목(새로 추가된 노트, 단방향 수정된 노트 및 보드)은 백그라운드에서 자동으로 동기화되며, 충돌이 발생한 항목만 수동으로 해결하도록 보존됩니다.
- **동기화 트리거 설정**: 화면 포커스 시점 및 노트 저장 시점의 동기화 검사 여부를 동기화 화면에서 직접 설정할 수 있으며, 수동 새로고침 버튼으로 언제든 최신 차이점을 확인할 수 있습니다.
